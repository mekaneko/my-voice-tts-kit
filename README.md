# wanwan-voice-tts-kit

自分の声を録音し、Style-Bert-VITS2 で学習して「テキスト入力 → 自分の声で読み上げ → MP3出力」までを行う、完全ローカル完結の個人用TTSシステムの制作キットです。コードと手順書一式を含み、同じ手順をたどれば誰でも自分の声のTTSを作れます。

> **プライバシー設計**：声は個人を特定できる生体情報に近いデータです。本プロジェクトでは、録音音声と学習済みモデルを端末の外に出さないことを設計原則としています。そのため本リポジトリに含まれるのはコードとドキュメントのみで、**音声データおよび学習済みモデルの重みは含まれていません**（`.gitignore` で除外済み）。

## システム構成

```
[台本 450文] → [専用録音アプリ] → [前処理・品質チェック] → [Style-Bert-VITS2 学習] → [推論アプリ]
   設計          48kHz/mono          44.1kHz化・無音除去       JP-Extra fine-tune      text → MP3
                              Whisperによる読み間違いQC
```

作り方は [SETUP.md](SETUP.md) に全手順があります。

### 1. 台本設計（450文）

- 日常会話、感情表現、朗読調などをバランスよく収録できるよう設計
- 感情文は「会話の7割くらいの強さ」で自然に演じる方針（音量ではなく抑揚で表現）

### 2. 専用録音アプリ「TTSボイス収録」（recorder-app/）

- 48kHz / モノラル / 16bit で録音し、文番号＝ファイル名（001.wav〜450.wav）で自動保存
- 録音停止後に自動再生、ピーク音量などの警告表示
- 録音のたびに台本対応表（CSV）と学習用ファイルリストを自動生成
- 台本と話者名は差し替え可能な汎用設計（他者への提供も想定）

### 3. 前処理と品質チェック（tools/）

- 44.1kHz化＋前後の無音トリミング（録音23.5分 → 実声19.6分）
- ローカルの Whisper（mlx-whisper small）で全450文を文字起こしし、台本と照合する読み間違いQCを実施（大半は表記ゆれによる誤検出で、実質的な読み間違いは数件のみ）

### 4. 学習（Style-Bert-VITS2 / JP-Extra）（training/）

- 事前学習モデルから fine-tune（batch 4、学習率 2e-4、全11,300ステップ）
- **本家は2026-11-08に完走**（Epoch 100、総学習時間43時間11分）。最終ロス：mel 26.6 → 20.2、g/total 48.5 → 36.0、KL 5.7 → 2.2。最終モデル `wanwan_e100_s11300.safetensors`（251MB、非公開）
- 進捗管理：1,000ステップごとにチェックポイントを保存し、**未学習のテスト文**を生成して Whisper で文字起こし、客観的に判読可能かを評価
- 未学習文「私はツイッターをやります」（台本・単語ともに学習データに存在しない）がステップ1,000時点で正しく発音できたことを確認 → 暗記ではなく汎化が起きている証拠

## 技術的なハイライト：MPS学習の不調をどう切り分けたか

Apple Silicon の GPU（MPS）で学習を開始したところ、**ロスは下がるのに生成音声がノイズのまま**という状態になりました。データ・特徴量・推論経路を順に検証しても異常がなかったため、「計算バックエンド自体が疑わしい」という仮説を立て、以下の切り分けを行いました。

1. **暗記テスト（overfit probe）**：16文だけを使い、学習済みの文を再現できるかを数百ステップで判定する小さな実験を設計
2. MPS：400ステップでも対象文を暗記できず、音声は断片の繰り返し。melロスは横ばい
3. CPU：**わずか100ステップで対象文を完全再現**（Whisper照合で完全一致）。melロスも 26.7 → 20.0 と健全に低下

結論：データや設定ではなく **MPSでの学習計算が不調**だったと特定し、本番学習をCPUに切り替えて完走させました。「ロスが下がっている＝学習できている」とは限らない、というのがこのプロジェクト最大の学びです。

## 推論アプリ「俺ボイスTTS」（tts-app/）

- テキスト入力 → 自分の声で合成 → 試聴 → MP3で保存（ffmpegで変換）
- 合成履歴（最新50件・再生／MP3保存／削除）
- 日本語文中の英単語や固有名詞は、読み辞書（表記→読み）で固定できる
- 起動時に最新の完成モデルを自動で読み込む。合成はCPUで実行（1文あたり約1〜数秒）

## 使用技術

- Style-Bert-VITS2（JP-Extra）、PyTorch（CPU学習）
- mlx-whisper（品質チェック・評価用）
- pywebview（録音アプリ・推論アプリのUI）
- ffmpeg（MP3変換）
- 実行環境：MacBook Pro（Apple M2 Pro、16GB RAM）、完全ローカル

※ ベースモデルおよび各ライブラリのライセンスは、それぞれの配布条件に従います。
