# 学習まわり

Style-Bert-VITS2（JP-Extra）の fine-tune 用スクリプトと設定例です。

## ファイル

- `train_ms_jp_extra_cpu.py` — CPU学習用に改造した学習スクリプト（DDPを外し、デバイスをCPUに固定、スレッド数を明示）
- `config_example.yml` — SBV2の config.yml の例（話者名は yourvoice に置き換え済み）

## 運用条件（本家の運用実績）

- batch_size 4、学習率 2e-4、100 epochs（数百文・約20分のデータで全11,300ステップ）
- 1,000ステップごとにチェックポイントと書き出しモデル（safetensors）を保存
- 所要時間: Apple M2 Pro のCPUで約43時間（他作業と並行した実績値。専念させれば短縮できる）

## ⚠️ 必読：MPS（Apple Silicon GPU）で学習しないこと

本家の検証では、MPSで学習すると **ロスが下がるのに生成音声がノイズのまま** という状態になりました。切り分けの結果、データや設定ではなくMPS側の学習計算が不調だったと特定しています。

切り分けに使った方法（他の環境でも有効）：

1. **暗記テスト（overfit probe）**：16文だけの小データで「学習済みの文を再現できるか」を数百ステップで判定する
2. MPS: 400ステップでも暗記できず → バックエンド異常と判断
3. CPU: 100ステップで完全再現 → CPUで本番学習を開始

「ロスが下がっている＝学習できている」とは限りません。新しい環境では、まず暗記テストで学習が成立するかを確認してから本番を回すことを強く推奨します。

## その他の注意

- transformers は **4.46.3** を使うこと（5.x では torch が無効化され学習が進まない事象を確認）
- 学習中はマシンをスリープさせない（macOSなら `caffeinate`）
- 進捗評価はロスだけでなく、チェックポイントで未学習文を生成して Whisper で文字起こしし、判読できるかで判断する
