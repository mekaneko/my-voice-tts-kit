# 補助ツール

学習データの品質チェックと、チェックポイントの試聴生成に使ったスクリプトです。パス中の話者名（myvoice）は自分の話者名に読み替えてください。

- `qc_asr.py` — 録音データセットの全WAVを mlx-whisper（small）で文字起こしし、台本テキストと照合して「読み間違い候補」を洗い出すQCスクリプト。表記ゆれによる誤検出が多いため、最終判断は目視（耳視）で行う
- `infer_trial.py` — 指定チェックポイントで試聴文を生成するサンプル。モデルパスは自分のチェックポイントに合わせて変更する
- `infer_overfit_trial.py` — 暗記テスト（overfit probe）の評価用。学習済み文を生成し、正しく再現できているかを確認する（training/README.md の切り分け手法を参照）
